\*\*Виконавець:\*\* Артєєва Оксана  

\*\*Спеціальність:\*\* Інженерія програмного забезпечення  

\*\*Група:\*\* 1 



\## Опис структури проєкту

\* `src/` — вихідний код модуля (`temperature.ts`).

\* `tests/` — набір автоматизованих тестів (`temperature.test.ts`).

\* `vitest.config.ts` — конфігурація тестового раннера Vitest та параметри покриття коду.

\* `tsconfig.json` — налаштування компілятора TypeScript.

\* `eslint.config.mjs` — конфігурація статичного аналізатора коду ESLint.

\* `.prettierrc` — правила форматування вихідного коду.

\* `.gitignore` — список файлів і каталогів, які ігноруються системою Git.
